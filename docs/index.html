How to add in Happ

  1. Open Happ, press the plus sign, choose Subscription.
  2. Name it anything clear, like Lumo ELITE.
  3. Paste the copied link with no spaces around it.
  4. Leave Encrypted subscription off, since these lists are open, and leave unsafe connections off, since every link here is https.
  5. Press Add. Happ pulls the servers in a couple of seconds. Repeat for each file you want.

How nodes get picked

Three rounds run about half a minute apart. TCP open time counts every round. TLS handshake counts where the node uses it. Where sing-box is present, Google generate_204, Cloudflare trace, an IP echo, a headers echo and three DNS queries over UDP go through the node itself.

A keeper answers in at least two rounds, keeps its exit IP off the checker IP, and leaves no checker address in headers. On full runs Google and Cloudflare must both answer through the node plus at least one UDP query, otherwise it ships nowhere. Reality with Vision ranks above plain transports at equal speed because it survives DPI better in practice.

The milliseconds in names come from the check runner. Happ measures from your machine, so its numbers differ, and n/a means the node stays silent on your network. Take the next row or refresh the subscription.

Questions

Why does Happ show n/a on some rows?

The runner and your machine take different roads to the node. A row with n/a stays silent on your network: the provider blocks it, the password died, or the node drowns in users. Take the next row. Reality rows and nearby countries answer most often.

How fresh are the lists?

Runs start at minute 17 every 3 hours, plus once on every code push. Happ rechecks on its own every few minutes, and the refresh button in the subscription pulls the newest batch at once.

What if a run finds nothing?

The previous files stay in place and only the stats update, with the reason shown at the top of this page. Happ never gets an empty list from us.

Is it anonymous?

The connection layer exposes nothing: no real IP in headers, traffic leaves from the node address. The server side still belongs to whoever published the node, so no free list can promise no logs. Run your own Reality node for traffic that must stay private.
