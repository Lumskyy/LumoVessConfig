How nodes get picked

Three rounds run about half a minute apart. TCP open time counts every round. TLS handshake counts where the node uses it. Where sing-box is present, Google generate_204, Cloudflare trace, an IP echo and a headers echo go through the node itself.

A keeper answers in at least two rounds, keeps its exit IP off the checker IP, and leaves no checker address in headers. Google plus Cloudflare answers lift the score. Reality with Vision ranks above plain transports at equal speed because it survives DPI better in practice.

Elite is a smaller file with harder rules: all three rounds green, both Google probes plus Cloudflare answering, HTTP median under 800 ms, TCP spread under 250 ms between rounds. The spread check drops nodes that freeze for a moment and recover, since those ruin games and calls even with a good median.

Free ranges still get flagged by Cloudflare and game filters, so Happ retests on your side. When a best node slows down, the next one in the file usually behaves better on that route.

Lists refresh at minute 17 every 3 hours. Sources are open subscriptions. Nothing here can promise no logs on someone else server.
